# Настройка источников Discount Parser

Эта инструкция относится к источникам типа website с collector `generic_web`.

## Главное правило

В поля маппинга не нужно вставлять целую строку HTML. Обычно туда вводится CSS-селектор элемента страницы. Поля с названием «Атрибут ...» содержат только имя HTML-атрибута.

Пример видимого промокода:

```html
<span class="promo-code">SALE20</span>
```

Настройка:
- Промокод: `.promo-code`
- Атрибут промокода: оставить пустым

Пример промокода в атрибуте:

```html
<button class="show-code" data-code="SALE20">Показать код</button>
```

Настройка:
- Промокод: `.show-code` или `[data-code]`
- Атрибут промокода: `data-code`

Пример input:

```html
<input class="promo" value="SALE20">
```

Настройка:
- Промокод: `input.promo`
- Атрибут промокода: `value`

## Поля маппинга

### Контейнер предложения
CSS-селектор одной повторяющейся карточки скидки или промокода. Все остальные селекторы ищутся внутри этой карточки.

Примеры: `.coupon-card`, `.offer`, `article.promo`.

### Название
CSS-селектор заголовка внутри карточки.

Примеры: `.coupon-title`, `h3`, `.offer-name`.

### Промокод
CSS-селектор элемента, в котором находится промокод. Это не сам текст промокода и не вся HTML-строка.

### Атрибут промокода
Заполняется только если код лежит не в видимом тексте элемента, а в HTML-атрибуте. Вводится только имя атрибута: `data-code`, `value`, `content` и т. п. Если код виден как обычный текст между HTML-тегами, поле нужно оставить пустым.

### Условия
CSS-селектор текста с условиями акции: минимальная сумма, категории, ограничения и т. п.

### Срок действия
CSS-селектор элемента, содержащего дату или текст срока действия.

### Ссылка
CSS-селектор ссылки на предложение. Обычно это `a`-элемент внутри карточки, например `a.offer-link`.

### Элемент раскрытия
Используется для сайтов, где промокод скрыт до нажатия «Показать код». Здесь задаётся CSS-селектор элемента, связанного с раскрытием.

### Атрибут раскрытия
Имя атрибута, из которого берётся идентификатор или код для раскрытия, например `data-coupon-id`. Если раскрытие не требуется, оба поля можно оставить пустыми.

## Как получить селектор

1. Откройте страницу источника в браузере.
2. Нажмите F12 или «Просмотреть код» / Inspect.
3. Выберите одну карточку предложения.
4. Найдите стабильный `class`, `id` или `data-*` атрибут.
5. Используйте короткий устойчивый CSS-селектор. Не используйте случайные классы, которые меняются после каждой загрузки страницы.
6. Сначала настройте контейнер карточки, затем остальные поля внутри него.
7. Сохраните источник и выполните «Проверить».

## Практический пример

```html
<article class="coupon-card">
  <h3 class="coupon-title">Скидка 20%</h3>
  <span class="promo-code">SALE20</span>
  <div class="conditions">При заказе от 3000 ₽</div>
  <time class="valid-until">до 31.08.2026</time>
  <a class="offer-link" href="/shop/sale20">Перейти</a>
</article>
```

Настройка:
- Контейнер предложения: `.coupon-card`
- Название: `.coupon-title`
- Промокод: `.promo-code`
- Атрибут промокода: пусто
- Условия: `.conditions`
- Срок действия: `.valid-until`
- Ссылка: `a.offer-link`
- Элемент раскрытия: пусто
- Атрибут раскрытия: пусто

Если после настройки источник возвращает 0 предложений, сначала проверьте именно «Контейнер предложения»: если он не совпал ни с одной карточкой, остальные селекторы тоже не сработают.
