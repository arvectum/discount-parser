# Discount Parser — устранение неполадок

Используйте этот документ по симптому. Если шаг не помогает, не применяйте случайные «чистилки», не удаляйте `.env` и не переустанавливайте Python: установленная Windows-версия самодостаточна.

## Setup: `IPersistFile::Save failed`, `0x80070005`, «Отказано в доступе»

Актуальный installer считает Desktop-ярлык необязательным. Ошибка сохранения ярлыка не должна откатывать установленный payload.

Проверьте:

1. существует ли `%LOCALAPPDATA%\DiscountParser\DiscountParser.exe`;
2. запускается ли Discount Parser из меню «Пуск»;
3. какой именно Setup использовался и его SHA-256;
4. приложите Setup log.

Не используйте «Запуск от имени администратора» как штатное решение. Если актуальный installer всё ещё откатывается из-за Desktop-ярлыка, это регрессия и её нужно эскалировать.

## `CreateProcess failed; code 2` / «Не удается найти указанный файл»

Ярлык указывает на отсутствующий EXE. Не создавайте новый ярлык вручную до проверки установки. Убедитесь, что `%LOCALAPPDATA%\DiscountParser\DiscountParser.exe` существует. Если файла нет — сохраните Setup log и переустановите актуальный installer; если файл есть — запускайте его или ярлык меню «Пуск» и передайте проблемный `.lnk` в диагностику.

## Программа установилась, но web-панель не открывается

Запустите из меню «Пуск», затем выполните из папки установки:

```text
DiscountParserWorker.exe doctor
DiscountParserWorker.exe status-json
```

Панель должна работать только на loopback (`127.0.0.1`/`localhost`). Невалидный Host и внешние cross-origin мутации намеренно блокируются.

## «Внутренняя ошибка сервера» / HTTP 500

Не копируйте traceback из случайных окон. Создайте support bundle:

```text
DiscountParserWorker.exe support-bundle
```

Запишите время ошибки и действие, которое её вызвало. Известные секреты автоматически редактируются, но `.env` отдельно не отправляйте.

## Подозрение на повреждение базы

Сначала:

```text
DiscountParserWorker.exe db-status
```

Если база здорова, `db-recover` не нужен. Если проверка сообщает повреждение:

```text
DiscountParserWorker.exe db-backup
DiscountParserWorker.exe db-recover
DiscountParserWorker.exe db-status
```

`db-recover` также создаёт резервную копию перед восстановлением. Сохраните каталог `recovery` до дальнейших действий.

## Telegram: `401 Unauthorized`

Это означает проблему авторизации бота. Проверьте токен в мастере настройки. Не отправляйте токен в чат поддержки или скриншотах. После изменения перезапустите приложение и проверьте состояние.

## Telegram: бот виден, но не может публиковать

Проверьте:

- правильный канал (`@username`/ID);
- бот добавлен в канал;
- у бота есть право публикации сообщений;
- в очереди есть `ready` предложения.

Если публикация ранее была `failed`, актуальная логика допускает повтор. `pending`/`published` повторно не выбираются.

## Источники не собираются или дают мало предложений

Откройте «Журнал» и `/system/status.json`. Смотрите `latest_status`, `last_error`, `last_success_at` и признак `stale`. Один упавший источник не следует лечить удалением общей базы.

Если проблема зависит от сети, зафиксируйте конкретный источник, URL, время и текущий режим маршрутизации. Для реальной проверки proxy/direct routing используется отдельный physical Windows gate.

## Прокси/VPN мешает локальной панели

Loopback должен идти напрямую. Не направляйте `127.0.0.1`, `localhost`, `::1` через внешний proxy. Локальная панель специально ограничена этими адресами.

## Настройки нужно перенести на другую установку

Экспортируйте только несекретные параметры:

```text
DiscountParserWorker.exe settings-export C:\Temp\settings.json
```

На целевой установке:

```text
DiscountParserWorker.exe settings-import C:\Temp\settings.json
```

Telegram/proxy/integration secrets вводятся отдельно и не должны присутствовать в экспортном JSON.

## Когда сразу эскалировать

Эскалируйте без дополнительных экспериментов, если:

- актуальный Setup откатывается при невозможности создать Desktop-ярлык;
- штатный EXE исчезает после успешного Setup;
- `db-recover` завершился ошибкой или новая база не проходит `db-status`;
- support bundle содержит секретное значение;
- web-панель принимает мутацию с внешним `Origin`/`Referer` или внешним Host;
- повторная публикация создаёт дубликат вместо ledger-защиты.

Минимальный комплект: скриншот, время, версия Windows, точное действие, support bundle; для установки — Setup log и SHA-256 installer.
