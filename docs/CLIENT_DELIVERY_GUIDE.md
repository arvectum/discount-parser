# Discount Parser — поставка заказчику

Этот документ описывает пользовательскую поставку. Заказчику не требуется Python, Git, pip, виртуальное окружение или ручное редактирование `.env`.

## Что передаётся заказчику

Сборки для Windows и macOS создаются отдельно. Нельзя передавать Windows-сборку пользователю macOS и наоборот.

### Windows

Предпочтительный файл поставки:

```text
DiscountParser-Setup.exe
```

Установщик содержит приложение со встроенным Python runtime.

### macOS

Передаётся отдельная macOS-сборка. До появления подписанного/notarized `.app` или `.pkg` используется пакет с `install.command` и frozen-приложением. Для внешней коммерческой поставки рекомендуется Apple signing/notarization.

## Windows: установка

1. Запустить `DiscountParser-Setup.exe`.
2. Пройти стандартный мастер установки.
3. Программа устанавливается в профиль текущего пользователя.
4. Автоматически выполняется миграция локальной SQLite-базы.
5. На рабочем столе и в меню Пуск создаётся ярлык `Discount Parser`.
6. На последнем шаге можно сразу открыть приложение.

Отдельно устанавливать Python или Git не нужно.

## Первый запуск

После запуска ярлыка приложение:

1. запускает локальный web server только на `127.0.0.1`;
2. автоматически открывает браузер;
3. проверяет, завершена ли первичная настройка;
4. если Telegram-настройки отсутствуют, показывает мастер настройки;
5. после настройки открывает панель управления.

Адрес панели по умолчанию:

```text
http://127.0.0.1:8765
```

Она доступна только на текущем компьютере.

## Какие данные вводятся при первом запуске

Обязательные поля:

- Bot Token — токен, полученный у BotFather;
- Telegram-канал — `@username` канала или числовой chat ID;
- Telegram user ID администратора — пользователь, которому разрешено управлять ботом.

Необязательное поле:

- имя бота — подпись для интерфейса.

Отдельный Telegram bot ID вводить не требуется: Telegram определяет бота по токену.

После сохранения приложение самостоятельно создаёт локальный `.env`. Пользователь не должен открывать или редактировать его вручную.

## Что доступно в web-панели

### Состояние системы

Отображаются:

- общее количество предложений;
- готовые к публикации;
- требующие проверки;
- опубликованные;
- истёкшие.

### Парсер

Можно вручную запустить сбор со всех включённых источников и увидеть состояние последнего запуска.

### Telegram-бот

Можно запускать и останавливать управляющего Telegram-бота.

### Scheduler

Можно запускать и останавливать автоматическое расписание парсинга, maintenance и autopost.

В packaged-режиме при последующих стартах приложения bot и scheduler автоматически запускаются, если первичная настройка уже завершена.

### Очередь публикации

Web UI использует тот же publication ledger и тот же фильтр, что Telegram `/queue` и autopost.

Из панели можно:

- увидеть следующие предложения;
- открыть исходную страницу;
- опубликовать предложение в Telegram-канал;
- отклонить предложение.

Повторная публикация одного Offer в тот же канал блокируется publication ledger.

### Фильтр публикации

Из браузера настраиваются:

- минимальный процент скидки;
- категория;
- подкатегория;
- тип предложения;
- магазин;
- максимальное количество публикаций за цикл;
- включение/выключение autopost.

### XLSX

Из панели можно:

1. скачать `offers.xlsx`;
2. исправить `category` и `subcategory`;
3. загрузить файл обратно.

Ручные исправления сохраняются как manual override и имеют приоритет над автоматической классификацией.

## Источники

Конфигурация источников хранится локально в `config/sources.yaml`. Код поддерживает сохранение состояния `enabled/disabled`; управление этим параметром переносится в web UI, чтобы заказчик не редактировал YAML вручную.

## Где хранятся данные

Локально на компьютере заказчика хранятся:

```text
.env
  Telegram-настройки и параметры приложения

discount_parser.db
  SQLite-база, история Offer, ParseRun, Publication и manual overrides

config/
  настройки источников и taxonomy
```

Данные не требуют отдельного сервера базы данных.

## Обновление

Обновление должно поставляться новой версией installer/package. Пользователь не должен выполнять `git pull` или `pip install`.

При обновлении необходимо сохранять пользовательские:

- `.env`;
- `discount_parser.db`;
- пользовательские настройки источников.

Миграции БД выполняются новым установщиком автоматически.

## Удаление

Windows `Setup.exe` создаёт стандартную запись приложения для удаления. Удаление программы и удаление пользовательской базы должны рассматриваться отдельно, чтобы случайно не удалить историю без явного выбора пользователя.

## Схема пользовательского сценария

```text
получил установщик
       ↓
запустил Setup
       ↓
ярлык Discount Parser
       ↓
двойной клик
       ↓
локальный web server
       ↓
браузер
       ↓
первый запуск? ── да ──→ Telegram Setup Wizard
       │                         ↓
       нет                  сохранить настройки
       │                         ↓
       └────────────────→ Dashboard
                              ↓
                 parser / bot / scheduler
                              ↓
                   filters / queue / XLSX
```
