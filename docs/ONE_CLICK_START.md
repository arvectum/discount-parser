# Discount Parser — запуск одной кнопкой

После первичной установки проект можно запускать двойным кликом без ручного ввода команд.

## Windows

Используйте файл в корне проекта:

```text
start_windows.bat
```

Двойной клик запускает единый runtime:

```text
Telegram bot + scheduler
```

Оба компонента работают в одном окне. Для остановки нажмите `Ctrl+C`.

Launcher автоматически проверяет наличие:

- `.venv\Scripts\python.exe`;
- `.env`.

Если установка или настройка ещё не выполнены, вместо запуска будет показано понятное сообщение об ошибке.

## macOS

Используйте файл:

```text
start_macos.command
```

После клонирования репозитория один раз разрешите его запуск:

```bash
chmod +x start_macos.command
```

После этого файл можно запускать двойным кликом в Finder.

Он запускает единый runtime:

```text
Telegram bot + scheduler
```

Для остановки нажмите `Ctrl+C` в открывшемся Terminal.

## Что запускается внутри

Оба launcher-файла вызывают одну и ту же кроссплатформенную команду:

```bash
python -m src.cli run
```

`run` запускает APScheduler в фоне и Telegram polling в основном процессе. При остановке Telegram-бота scheduler также корректно завершается.

## Что нужно сделать только один раз перед первым запуском

Перед использованием одной кнопки должна быть выполнена первичная установка:

1. установлен Python 3.11+;
2. создана `.venv`;
3. установлены зависимости;
4. создан и заполнен `.env`;
5. выполнено `alembic upgrade head`.

Подробно это описано в `docs/USER_INSTALLATION_GUIDE.md`.

После этого для обычного ежедневного запуска терминальные команды не нужны.
