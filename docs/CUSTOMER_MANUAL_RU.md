# Discount Parser — руководство пользователя

## Установка и обновление

Закройте запущенный Discount Parser и запустите `DiscountParser-Setup.exe` обычным способом. Права администратора для штатной установки в профиль пользователя не требуются. Основной файл находится в `%LOCALAPPDATA%\DiscountParser\DiscountParser.exe`.

Ярлык в меню «Пуск» является штатным способом запуска. Ярлык на рабочем столе дополнительный: если Windows запрещает его создать, установка приложения всё равно должна завершиться успешно. Новый Setup можно запускать поверх существующей версии.

## Первый запуск

Мастер настройки попросит токен Telegram-бота, имя бота, канал публикации (`@username` или channel ID) и Telegram user ID администратора. Эти значения хранятся локально. Диагностический архив и переносимый экспорт настроек по контракту не должны содержать секреты.

## Рабочий цикл

1. Запустите сбор предложений или дождитесь scheduler.
2. На странице журнала проверьте источники и последние запуски.
3. Просмотрите предложения; сомнительные позиции остаются в `needs_review`.
4. Настройте фильтр публикации: скидка, категория, магазин, регион/город и лимит.
5. Публикуйте позиции `ready`. Позиции с `failed` могут быть повторены; уже `pending`/`published` повторно в очередь не попадают.

## Состояние системы

Машиночитаемый статус доступен в панели как `GET /system/status.json` и в установленной поставке:

```text
DiscountParserWorker.exe status-json
```

`ok` означает нормальную работу; `warning` — требуется внимание; `error` — не пройдена обязательная проверка.

## Диагностика

Безопасный архив для поддержки:

```text
DiscountParserWorker.exe support-bundle
```

Он не включает `.env` и рабочую SQLite-базу и проходит через редактирование известных секретов. Для поддержки отправляйте этот архив, а не всю папку программы.

## База данных и восстановление

Проверка:

```text
DiscountParserWorker.exe db-status
```

Резервная копия базы, WAL и SHM:

```text
DiscountParserWorker.exe db-backup
```

Восстановление при подтверждённом повреждении:

```text
DiscountParserWorker.exe db-recover
```

Перед восстановлением создаётся локальная резервная копия. `.env` и Telegram-настройки не являются частью базы и не удаляются этой процедурой. Не используйте `db-recover` как способ очистки данных при обычной ошибке источника или Telegram.

## Экспорт и импорт несекретных настроек

Экспорт:

```text
DiscountParserWorker.exe settings-export
DiscountParserWorker.exe settings-export C:\Temp\discount-parser-settings.json
```

Импорт:

```text
DiscountParserWorker.exe settings-import C:\Temp\discount-parser-settings.json
```

Экспорт содержит только allowlist несекретных эксплуатационных параметров. Токены, пароли, channel/admin ID, MTProto credentials/session, proxy URL/username и VK access token не экспортируются. Импорт принимает только известную схему и не заменяет уже сохранённые секретные строки `.env`.

## Завершение и удаление

Для обычного завершения используйте кнопку «Завершить Discount Parser» на странице «Система»: она останавливает bot, scheduler и локальную панель. Для удаления используйте штатный uninstall. До ручного удаления каталогов сохраните нужную базу и экспорт настроек.

## Что отправлять в поддержку

Сообщите действие и шаг ошибки, версию Windows, время ошибки и приложите скриншот и support bundle. Для проблем Setup также нужен Setup log и, если известен, SHA-256 установщика. Не отправляйте токен Telegram-бота, `.env`, пароль прокси или рабочую базу без отдельной договорённости.
