# R11 — Unified Publication Format

## Цель

Telegram-публикация должна выглядеть одинаково независимо от источника и не копировать длинный рекламный текст объявления.

Полный `Offer.description` сохраняется в базе и остаётся доступным на странице проверки, но **не является частью Telegram-поста**.

## Базовый порядок

1. Короткий нормализованный заголовок.
2. Поставщик.
3. Цена, если известны старая и новая цена.
4. Скидка.
5. Кэшбэк.
6. Доставка.
7. Категория и подкатегория.
8. Условия скидки.
9. ГЕО.
10. Срок действия.
11. Промокод.
12. Отдельная inline-кнопка перехода к предложению.

Пример:

```text
🔥 Скидка на продукты 25%

🏪 Поставщик: Лента
💸 Скидка: 25%
📂 Категория: Продукты
📌 Условия: заказ от 3 000 ₽; скидка не более 700 ₽
📍 ГЕО: Вся Россия
⏳ До: 18.08.2026
🎁 Промокод: SUMMER25
```

## Самостоятельная настройка заказчиком

В `Настройки → Формат публикации Telegram` пользователь может без редактирования кода:

- включать и отключать отдельные поля;
- менять порядок полей стрелками;
- менять порядок drag-and-drop;
- видеть live preview;
- вернуть стандартный формат одной кнопкой.

Настраиваемые поля:

- Поставщик;
- Цена;
- Скидка;
- Кэшбэк;
- Доставка;
- Категория;
- Условия;
- ГЕО;
- Срок действия;
- Промокод.

Заголовок и inline-кнопка перехода не относятся к списку отключаемых колонок и остаются частью публикации.

Настройка сохраняется в mutable runtime state:

`telegram_publication_format.json`

Файл находится в том же runtime root, где приложение хранит рабочие локальные данные. На Windows/macOS frozen delivery и Linux server путь определяется общей функцией `runtime_root()`.

При отсутствии файла используется полный стандартный R11-формат. Старые установки поэтому продолжают работать без дополнительной настройки.

## Правила renderer

- `description` никогда не копируется в публикацию.
- Заголовок берётся из `display_title`, а если его нет — из `title`; слишком длинный заголовок обрезается.
- Renderer читает сохранённый список включённых полей и порядок перед формированием поста.
- Пустые поля не показываются, даже если пользователь включил их в шаблоне.
- Если ГЕО отключено пользователем, строка ГЕО не выводится; если включено — показывается конкретный город/регион, `Вся Россия` или `Не указано`.
- Если есть явное `Offer.conditions`, оно используется без дублирования структурированными ограничениями.
- `min_order_amount` и `max_discount_amount` используются как fallback для условий, когда явного `conditions` нет.
- Длинные значения каждого поля ограничиваются до компактного размера.
- Исходный текст остаётся доступен оператору в `/review`.
- `/review` показывает preview фактического Telegram-renderer с текущей сохранённой пользовательской настройкой.
- Новые Publication записываются с `template_version = v2`.

## Почему без AI-summary на этапе публикации

R11 намеренно строит публикацию детерминированно из структурированных данных. Это делает формат одинаковым, тестируемым и не даёт генеративной модели придумать условия акции. Смысловая обработка длинного исходника происходит раньше — при извлечении нормализованных полей.

Если критически важное условие не удалось извлечь, предложение должно быть проверено оператором через `needs_review`, а не публиковаться с произвольным пересказом исходного текста.

## Acceptance

- два Offer с одинаковыми структурированными полями, но разным объёмом `description`, рендерятся одинаково;
- рекламный текст из `description` отсутствует в Telegram caption;
- стандартная установка без пользовательского config сохраняет полный R11-формат;
- пользователь может оставить, например, только Поставщика + Скидку + Категорию + Условия;
- порядок полей в реальном Telegram renderer совпадает с сохранённым порядком;
- неизвестные/дублирующиеся ключи конфигурации безопасно нормализуются;
- `/settings` содержит понятный переход к редактору формата;
- editor показывает live preview и кнопку сброса;
- `/review` показывает исходный текст отдельно от preview публикации;
- существующая кнопка перехода и Telegram HTML escaping сохраняются;
- новые публикации маркируются template version `v2`.
